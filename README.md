# 论文库

> [!summary] 最短使用方法
> 新论文只做三件事：放入原文/译文、从模板建立一张论文主卡、填写 research_direction。方向分类、资料入口和代码入口由下方工作台自动生成，不维护手工索引。

![[论文工作台.base]]

## 新增论文

1. 原文放入 附件/论文原文/，译文放入 附件/论文译文/。
2. 使用 [[模板/论文阅读卡片模板]] 建立 论文库/年份-短名-主题.md。
3. 填写 research_direction；需要关联时，在正文直接写 [[相关论文]] 或 [[相关概念]]。

## 开源项目
