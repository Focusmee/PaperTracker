# 元数据与链接规范

## 论文卡最小属性

| 属性 | 用途 |
|---|---|
| type: source | 让自动工作台只读取论文卡 |
| title | 正式题目或稳定中文标题 |
| research_direction | 手动选择主要研究方向 |
| research_type | 应用型、探索型、综述型、评测型 |
| status | unread、reading、done、paused |
| venue、publication_date | 发表场所和年份 |
| local_pdf | 本地原文 Wiki Link |
| translation_pdf | 本地译文 Wiki Link；没有则为空 |
| code_url | 官方代码地址；没有则为空 |
| doi | DOI；没有或未核实则为空 |
| parent | 论文卡统一为 [[README]] |

domain 可以补充 1–3 个交叉领域，但不要求为它们建立目录或地图。

## 链接

- parent 只负责回到首页。
- related 是可选快捷入口，不要求持续维护。
- 正文链接用于表达具体关系，例如“方法相似”“数据集相同”或“结论冲突”。
- Obsidian 反向链接会自动显示哪些笔记提到当前论文或概念，无需维护双向链接。

## 文件命名

- 论文卡：年份-短名-中文主题.md。
- 原文：附件/论文原文/<稳定文件名>.pdf。
- 译文：附件/论文译文/<稳定文件名>.pdf。
- 关键图：附件/论文截图/<论文短名>-图号-说明.png。
- 项目：项目/<项目名>/00 项目主页.md。

## 内容可信度

笔记应区分“来源事实”“我的理解”“待验证”。重要数字应能回到论文页码、章节、图或表；代码观察不能冒充论文作者结论。
