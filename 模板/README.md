# 模板使用说明

本库只保留两个模板：

1. [[模板/论文阅读卡片模板]]：一篇论文一张主卡，泛读和精读都写在同一文件。
2. [[模板/开源项目阅读模板]]：一个仓库一张项目主页。

新增论文后只需填写 research_direction，自动工作台会完成方向分组和资料入口展示。
