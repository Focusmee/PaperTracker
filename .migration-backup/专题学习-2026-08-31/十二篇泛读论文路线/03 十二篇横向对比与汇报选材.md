# 十二篇横向对比与汇报选材

## 一张表看清位置

| 论文 | 研究对象 | 核心方法 | 最适合给哪篇精读补充 | 泛读时只记什么 |
|---|---|---|---|---|
| MATE | 移动 Agent 轨迹 | 策略条件化轨迹审计 | ScenGen、DIULENS | 轨迹生产与轨迹审计的分工 |
| TPL Developers | 第三方库开发者 | 正文待公开 | PINFINDER | 上游责任；不要编造结果 |
| Android AR Privacy | AR App 数据访问 | 静态候选+Frida确认 | HScope、DIULENS | 领域API知识与双阶段确认 |
| Plain Text, Plain Risks | Android WebView | 大规模静态筛选+系统级动态监控 | PINFINDER、DIULENS | 候选、运行事实、归因三层 |
| Bridges to Self | Web-to-App追踪 | 网页/App静动态多源关联 | DIULENS | 同意前跨上下文副作用 |
| Health Hazard | Health Connect | 合成示踪数据+Hook+网络证据 | DIULENS、ScenGen | 声明、API、外传三角验证 |
| BINREX | 二进制任务 | 检索+规划+IDAPython+验证 | ScenGen、HScope | Agent必须调用工具并验证 |
| PANGOLIN | IoT固件 | LLM接口恢复+模糊测试 | ScenGen | 模型理解与执行证据分离 |
| LLMxCPG | 源码漏洞检测 | CPG切片+LLM | HScope | 结构化裁剪而非塞入全仓库 |
| IRIS | Java漏洞静态分析 | LLM规格+CodeQL路径 | HScope、PINFINDER | LLM补知识、工具算路径 |
| LLM4Decompile | 二进制表示恢复 | 端到端/反编译结果改写 | HScope、BINREX | 表示恢复不等于漏洞检测 |
| BugAuditor | 大型项目代码 | 从防御代码归纳项目规则 | PINFINDER | 一致模式可形成候选Oracle |

## 按课堂问题选论文

| 老师追问 | 最合适的泛读论文 | 你要回答的核心 |
|---|---|---|
| 怎么批量测试成千上万 App？ | Plain Text, Plain Risks | 先静态便宜筛选，再对候选动态运行，多机并行 |
| 如何知道隐私声明与行为不一致？ | Health Hazard、Android AR Privacy | 把披露、API调用、网络或运行确认放在同一证据链 |
| Agent 点错后怎么办？ | MATE、BINREX | 保存轨迹、定义验证条件、失败重试和事后策略审计 |
| 为什么不把全仓库交给 LLM？ | LLMxCPG、IRIS | 用程序图切片或静态规格减少噪声，并保留工具路径 |
| 知识库到底存什么？ | PINFINDER+IRIS+MATE对照 | API/规则、Source/Sink、App工作流与策略，依任务不同 |
| LLM 怎样参与但不主导事实？ | PANGOLIN、BINREX、BugAuditor | 模型负责语义，工具负责执行，人工负责确认 |
| 同意界面之外还有什么旁路？ | Bridges to Self | Web-to-App 本机通道可产生跨上下文关联 |

## 推荐汇报中只选4篇泛读作支撑

主汇报仍讲四篇精读。泛读论文只在对应位置各出现一句：

1. **Plain Text, Plain Risks**：说明大规模测量为何采用静态筛选加动态验证。
2. **Health Hazard**：说明声明、API 和网络证据怎样三角验证。
3. **IRIS**：说明 LLM 适合生成规格，CodeQL 等工具负责路径计算。
4. **BINREX**：说明 Agent 应有明确工具调用和可验证完成条件。

备选：如果老师更关注供应链社会责任，用 TPL Developers 替换 BINREX，但必须说明正文尚未公开。

## 升级为精读的判据

每篇给0–2分：

| 判断项 | 0分 | 1分 | 2分 |
|---|---|---|---|
| 与当前研究 | 弱相关 | 方法可借鉴 | 直接改变研究问题或Demo |
| 正文与材料 | 不可得 | 只有正文 | 正文、代码、数据均较完整 |
| 可复现性 | 依赖特殊硬件/数据 | 能做思想Demo | 一周可跑最小复现 |
| 汇报价值 | 只能做背景 | 有一项清晰比较 | 能回答老师关键追问 |

总分6分以上再进入精读候选；否则保留五格卡即可。

## 最少记忆清单

- 泛读论文是精读主线的证据和方法补充，不是汇报主体。
- 课堂支撑优先选择 Plain Text、Health Hazard、IRIS、BINREX。
- 是否升级精读由研究相关性、材料、复现和汇报价值共同决定。
